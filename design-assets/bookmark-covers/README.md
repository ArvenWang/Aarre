## 生成规范

- 模式：Codex 内置图片生成工具。
- 用途：Aarre 书签列表的方形分类封面与缩略图。
- 构图：`1:1`，只保留一个中心符号，不使用人物、手、场景或动作链；缩小到 `48 × 48` 仍可辨认。
- 风格：近黑色 `#141413` 粗手绘线条、不规则象牙白 `#FAF9F5` 承载形、单一强调色满版背景。
- 文本：无文字、无 Logo、无水印。
- 排除：透明背景、白色外画布、摄影感、3D、精细企业矢量风格和复杂小细节。

内置生成模型仍保留了轻微的同色明暗变化，因此当前版本不应描述为“像素级纯色填充”；在产品实际 `48 × 48` 缩略图尺寸下不影响识别。

- 所有图片均为 RGB、不透明画布。
- 后续迭代继续使用新版本号，不得覆盖现有版本。
