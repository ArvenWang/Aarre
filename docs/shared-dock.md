# Aarre / NexAlign 共享 PC 入口（协议 v1）

两个扩展均升级后，在两边都允许显示快捷入口的普通 HTTP(S) 页面合并为一个可左右贴边的手柄。手柄从上到下显示 Aarre 与 NexAlign 的正式应用图标；悬停或键盘聚焦 Aarre 后，向页面内侧出现添加当前网页到收藏的星标；菜单顶部不增加应用切换栏；先收起当前菜单，再从手柄打开另一个应用，同一页面只展开一个应用。原有手机模拟/Chrome 原生手机侧栏保留。

## 外观与状态

- 共享手柄为 52 × 96px，独立安装为 52 × 52px。距所停靠的左边或右边 **8px**，四个角均为 16px；两个入口均为 44 × 44px、圆角 12px，外侧内边距 4px，两个 44px 点击区相邻，不加分隔线。一级入口复用两款应用的正式图标，36px / R8，居中显示；可见图标之间、图标至外框均为 8px；二级收藏星标为 22px / 1.5px 描边。
- 把手拖动时同时跟随横向和纵向指针，松手后按中心所在半区吸附最近的左右边缘，恰在中线时保留原边。上下各保留 8px 边界；拖动后不触发菜单点击，指针取消或窗口失焦也结束拖动并吸附。上下方向键微调、左右方向键换边，支持 Shift 加速及 Home / End。保存边缘与纵向比例，刷新后恢复；旧设置默认继续靠右。配对手柄使用首个槽位的行程归一化，贴底后的反向移动没有空行程。
- 两宿主共用 `src/shared/suite-dock/drag.ts`。配对时由 Aarre 绘制把手并发布位置，NexAlign 使用同一位置展开、收起；独立安装复用相同控制器。位置通过各自已有设置持久化，Aarre 顺序写入并防止迟到的初始化数据覆盖刚完成的调整。
- Aarre 的星标在悬停或键盘聚焦后，显示于朝页面内侧的 52 × 52px 二级操作中；保留鼠标间隙缓冲、Tab 进入和 Esc 关闭。主入口悬停只使用轻微底色，按下稍加深，不增加描边或缩放。二级收藏操作的外壳和按钮均无边框，悬停只改变外壳底色，内部按钮保持透明；已收藏由实心星标表达，不再显示内层选中框和小状态点。键盘 focus-visible 保留单一细轮廓。拖动时收起二级操作，避免误点收藏。
- 星标沿用原收藏流程：打开当前网页的收藏表单，取消不保存；已收藏时点击管理已有收藏。图标内嵌于共享文件，不依赖网络图片或新增网页资源权限。
- 两个主菜单共用 `src/shared/suite-dock/geometry.ts`，高度为当前可用视口减去上下各 12px，窗口变化时同时遵循同一规则；两个菜单均距所停靠边缘 8px，四角 20px，改宽把手始终位于内侧边缘；收藏表单继续独立计算高度，并在靠近上下边缘时向可用区域避让。
- 两边宿主直接调用相同的 `src/shared/suite-dock/morph.ts`，底板展开 280ms、收起 210ms；内容淡入 140ms（延后 100ms）、淡出 120ms，不叠加装饰性入场位移。文字和 iframe 保持真实尺寸；只有停靠边缘实际变化时，内容和操作入口按底板相同的时长、缓动同步平移。反向操作从当前显示状态继续，重复就绪/状态消息不重启动画，过渡中视口或表单变高不会延长原截止时间；系统“减少动态效果”下立即切换。
- PC 菜单始终按当前可用视口保持所停靠边缘 8px 距离，不保留空凹槽。NexAlign 的 `floating-host.css` 随内容脚本预载，仅匹配处于展开状态的桌面宿主；点击当帧即隐藏原生滚动条，展开直接以释放后的宽度为目标，后台准备延迟不会造成第二段位移。菜单内容、关闭按钮或把手与底板同步平移，只移动实际产生的宽度差，没有滚动条宽度变化时不横移。关闭后恢复网页滚动条，并从当前呈现位置平滑返回；宿主移除后预载规则自动失效。手机宿主不匹配该规则。手动注入旧标签页时也先装载相同样式文件。
- 共用入口使用相同中性色；界面明暗采用最后一次明确设置。NexAlign 的“跟随系统”在两边分别按同一系统设置解析；网页本身的明暗控制仍是独立功能。
- 历史版本没有记录设置时间。首次连接只做确定性迁移（同为旧记录时采用 NexAlign 的现有偏好），不会伪造历史时间；升级后在任意一边设置一次主题即可建立最新偏好。
- 共享主题记录只保存在本机，不新增云端实体。Aarre 既有主题字段仍按其现有设置同步规则处理；页面启动/旧值恢复不会被算作一次新的手动设置。

## 切换与恢复

Chrome 会限制扩展调试含有另一扩展 iframe 的页面。因此切换时需要先保存当前 UI 状态，释放其 iframe，再打开另一个扩展。仅隐藏 iframe 不够。

- NexAlign 在交接完成前暂停检查、清除覆盖层、释放调试连接；Figma 状态和菜单标签保存后可重新建立安全握手。
- Aarre 保留输入草稿、收藏表单、当前视图、收藏树展开和滚动位置。业务状态留在 Aarre 自己的存储里。
- 保存失败、仍在执行的操作以及尚未保存的 AI 设置会阻止释放页面，并显示原因；不会为了切换而丢弃它们。
- 连接按 Chrome 提供的 tabId / documentId 匹配。断连、卸载或重新加载后恢复单插件入口；重新握手成功才再次合并。快速切换按最新意图排序，已开始的清理必须先完成。
- 对方的 Port 对象并不等于对方仍然运行。协调端每两秒确认一次外部客户端存活；连续一次未回应即移除过期成员，覆盖 Chrome 在加载中页面上未及时通知卸载的情况。

## 手机模式的入口隐藏

NexAlign 0.1.2 / Aarre 0.6.32 起，手机模拟及切换过程中隐藏当前标签页的 Aarre 整个悬浮宿主，并设为不可聚焦/不可点击；切回桌面、退出或连接失效后恢复。其他标签页与用户的入口开关、停靠位置保持原样。

`viewport.ts` 使用独立的 `nex-suite-viewport-v1` 后台连接传递当前手机标签页 ID。仅接受 Manifest 允许列表内、来自扩展自身页面且没有 `sender.tab` 的发布者；网页和内容脚本不能签发隐藏状态。状态属于活连接，不写入持久设置，跨页面刷新保留；后台重连会重新发布，2 秒探活、最多 4 秒清理失效连接。`STATE.suppressed` 为可选字段，旧版协议仍可解析。
