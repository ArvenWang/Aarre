# 浮层表面规范

页面、模态弹窗、弹出菜单使用独立的语义表面，避免暗色下所有内容共用页面底色。

| 层级 | 接入方式 | 暗色背景 |
| --- | --- | --- |
| 页面 / 完整目的页 | 默认 `--surface` | `#16181b` |
| 模态弹窗 | `AppModal` 默认的 `data-elevation="dialog"` | `#24272a` |
| 下拉 / 菜单 / 文件夹选择 | `data-elevation="popover"` | `#34383c` |

- 颜色、边界和阴影统一定义在 `src/ui/tokens.css`，由 `heroui-theme.css` 在浮层边界建立表面上下文。不要为某一个设置窗单写暗色背景。
- 表面上下文同时更新 `--surface`、`--surface-sunken`、边框、阴影、弱提示和表单变量。内部面板、滚动区域、页脚与控件继承它，避免重新露出页面底色。
- Portal 弹层须在自身根节点声明层级。共享 `Select` 已自动接入；更多菜单和文件夹选择共用同一规则。
- `AppModal presentation="page"` 用于借助模态焦点管理呈现完整目的页（如直接展开的添加收藏），保留页面表面。
- 浅色模式保持白色表面，以统一边框、叠加阴影和原有遮罩区分层级。暗色额外通过逐层提高明度区分，弱提示文字同步提高亮度。
- 当前适用范围：Aarre 的悬浮菜单、侧面板和完整收藏库。图像预览等特殊内容仍可按其语义设置内部画布；无需更改通用浮层边界。
