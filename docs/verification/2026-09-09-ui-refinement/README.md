# Aarre 0.6.1 视觉细节复核

本轮按用户要求，对照 NexAlign 的滚动、留白和控件比例进行检查。保留 HeroUI，所有修复进入实际产品组件。开发预览使用隔离的本地数据，不代表已安装 Chrome 或真实 AI 服务验收。

## 已发现并修复

| 问题 | 修复与可验证目标 |
| --- | --- |
| 多个区域只有隐藏原生滚动条，没有可拖动替代 | 所有滚动入口共用双轴组件；5px 细条、12px 命中区，无底轨、不占正文宽度 |
| 收藏列表和管理页有不同的滚动实现 | 删除重复实现，统一拖动、键盘、边缘唤醒及闲置渐隐行为 |
| 下拉箭头贴边，选中标记可能与长文字重叠 | 箭头内侧留白 12px；文字、箭头和选中标记参与正常布局 |
| 下拉值 16px、触发器 12px，弹出层使用旧宽度变量 | 控件/选中值统一 13px；常规高 32–40px，弹出层跟随触发器宽度 |
| 紧凑辅助文字 11px；Portal 编辑窗口未继承密度 | 辅助文字至少 12px，主题与密度覆盖整个文档及弹层 |
| 编辑标题下多余留白、输入框嵌套 padding、AI 入口偏高 | 收紧无意义留白；菜单和管理页编辑均固定标题及底部操作区，长内容只滚动正文 |
| 长表格/代码将 AI 正文撑宽，正文右侧被裁掉 | Grid 使用可收缩列；表格与代码内部横向滚动，正文不横溢出 |
| 历史列表重复缩进，摘要混入后续 Markdown 标记 | 减少内层 padding；摘要使用首段阅读片段 |
| 管理页搜索框有双重阴影，窄窗主题按钮独占一行 | 修正实际组件类名，窄窗头部排成两行并正确锚定导航滚动条 |
| 窄窗“补齐缺失封面”按钮文字贴边 | 保留 12px 水平内边距 |
| 从管理页打开设置时字段样式缺失 | 字段排版归入 SettingsPage 自身加载的共享样式 |
| 弹层中间包装影响直接子项样式，外层重复留白 | 保留 HeroUI 焦点管理，使用不可见引用锚点，使业务正文保持直接子项结构 |
| 备份/设置直接入口被 Tabs 的集合发现阶段重复创建，两个窗口互相屏蔽点击 | 状态与 Portal 移到 Tabs 外；直接链接只打开一个窗口，关闭、重开均保留一个实例；新增真实组件集成回归 |

## 证据与边界

- `before/`：本轮发现的问题及 NexAlign 的存档参考画面。`nexalign-reference.png` 来自另一个仓库的既有截图，不是本轮重新运行 NexAlign 的结果。
- `final/`：真实浏览器渲染图。开发预览的 309 条收藏、22 个 QA 会话与长备注均为明示的隔离测试场景；没有提交到用户的 Chrome 数据或调用真实 AI 服务。
- `menu-geometry.json`、`manager-geometry.json`：控件尺寸、箭头留白、滚动区域及页面宽度量测。
- `long-content.json`：宽表格、长代码、窄窗正文与键盘横向滚动。
- `scroll-drag.json`：实际鼠标拖动与渐隐。为了拍到中间帧，临时暂停真实 CSS 过渡于 40ms，随后恢复播放；未替换产品 CSS 或绘制假的滚动条。
- `secondary-geometry.json`、`shared-settings-fields.json`：补充弹层、引导与共享字段量测。
- `final-dialog-checks.json`：最终管理编辑窗口的留白、固定操作区、窄窗删除确认、焦点约束、Escape 分层及单实例弹层。最新量测优先于前序截图阶段的同名场景。
- `source-watch.json`：写入验收证据前后页面导航时间相同，确认取证不再导致预览刷新。
- `verify-*.mjs`：Ego Browser 回放脚本。任务空间编号和本机绝对路径属于本次环境；复用时先创建自己的任务空间再调整编号。部分 `display: contents` 元素没有布局矩形，验收脚本应等待其可见字段。

## 实际已验证的关键数值

- 35px 鼠标拖动使收藏列表偏移由 280px 变为 537.5px；拖动时透明度 1，渐隐中间帧 0.39278，闲置后为 0。
- 渐隐过渡 160ms；约 850ms 闲置后触发。键盘聚焦或正在拖动时保持显示。
- 滚动前后正文宽度均为 384px，轨道背景完全透明；细条 5px，透明命中区 12px。
- 菜单与管理页实测下拉箭头距边框内侧均为 12px；触发器高 40px，值字号 13px。
- 400px 窗口中，AI 正文可用宽 384px；表格/代码容器宽 352px，分别容纳约 708px / 1134px 的内容。320px 窗口正文宽与滚动宽均为 304px。

## 回到电脑后的安装态验收

1. 从 0.6.1 解压目录加载或更新扩展，再刷新普通网页。
2. 在收藏、设置、下拉列表、长备注中滚动并停下，确认细条浮现后淡出，没有底槽，也不挤动文字。
3. 拖动细条到两端；键盘 Tab 到滚动条后试方向键、Home/End。
4. 明暗主题分别打开模型、文件夹选择与编辑窗口，检查箭头、文字、选中标记和四周留白。
5. 缩窄菜单、打开完整收藏库，再检查设置、备份、编辑和封面补齐确认窗口。
6. 使用真实长回答核对宽表格/代码。真实 Provider、云端和原生 Chrome 写操作仍属于独立验收；服务端本轮没有部署。

最终检查与交付身份以根目录 `AGENT_PROGRESS.md` 和 `outputs/Bookmark-Layer-0.6.1-build.json` 为准。
