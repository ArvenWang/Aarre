## 本轮发现并解决

- 原表单和宿主均沿用工作区全高，导致大块留白；现以独立尺寸和内容高度取代。
- 入场动画的缩放会污染 `getBoundingClientRect` 高度；改用不受变换影响的布局高度，尺寸未变时不重复请求，避免反馈循环。
- 正式构建 CSS 的加载顺序会让共享弹窗标题/底部的 margin 覆盖专用样式，进而挤掉提示文字；已加专用范围的明确优先级，并在浏览器中反转样式顺序核验。
- 旧文件夹列表在表单内绝对定位，紧凑面板会裁掉末尾；现由 HeroUI 浮层自动放置。短窗口浮层中的滚动区也随实际可用高度缩小，末尾入口可完整点击。
- 旧下拉按 Escape 会关闭整个表单；嵌套组件浮层现在只关闭自身，填写内容保留。真实 Chrome 和集成测试均覆盖。
