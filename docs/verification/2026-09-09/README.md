## 视觉检查中实际修正的问题

- HeroUI 默认 Tab 宽度使管理导航每项占满一行；浮动导航的最小宽度又造成窄窗溢出。已按真实截图修正并重拍。
- 悬浮搜索与列表缺少原有密度/布局条件，设置出现大段空白。已恢复明确的内容滚动容器。
- 编辑内容较长时操作区遮住字段；备份对话框原先顶在视口顶部。已调整正文/操作区分工与弹窗居中，360px 和桌面分别看图。
- 开关的可访问名称放在了错误的组合部件上，原生输入没有正确名称。已修正到根控件，并通过 Space 操作验证。
- 浅色辅助文字与警示色、深色危险按钮文字对比度不足；图谱文字随景深过小过淡。已提高对比度与最小字号，并重新查看成对截图。
- 减少动态效果规则被更具体的控件样式覆盖。仅对固定的动画/过渡属性允许可访问性覆盖，实际确认控件过渡降为 0.01ms。
- AI 尚未配置时整页缺少上下文。现在解释用途和配置入口；配置后的起始提问会填入真实输入框，不自动提交。

`intermediate/` 保存部分中间结果。它们包含修正前的布局或实验数据，不是最终合格截图。早期搜索试验混合了更新与动画帧等待；最终 JSON 分别记录 DOM 与显示帧，保留先前结果用于追溯。修改证据文件可能触发 Vite/Tailwind 热更新，重建预览不属于生产扩展生命周期结论。

## 回到电脑后的验收顺序

1. **核对安装。** 新测试配置在 `chrome://extensions` 开启开发者模式，加载 `outputs/Bookmark-Layer-0.6.0-unpacked`。已有开发安装先核对实际路径；若加载的是本仓库 `dist`，刷新扩展并刷新网页即可。保留现有本地数据，不用卸载旧扩展来刷新。
2. **看新入口。** 在普通网页用球和 `Alt+Shift+B` 开关菜单；拖到四角、改变大小、切换标签与两个窗口、按网站隐藏再恢复。检查是否遮挡、抢焦点或出现多个球。
3. **做一次完整收藏操作。** 用明确的测试网址收藏、改名、加备注、换目录、删除、撤销；同时在 Chrome 书签管理器核对结果。长中文备注刷新后应可继续编辑。
4. **看明暗与窄窗。** 收藏、AI、设置、编辑和五个管理页各走一遍。小窗口下保存、取消、发送/停止可达；键盘焦点清楚，Escape 逐层退出。
5. **备份恢复使用独立测试配置。** 导出完整文件，核对预览数量，再在空测试配置恢复；检查文件夹顺序、同网址的不同位置、备注、标签和图片；重复导入应被识别。
6. **云端在服务端升级后验收。** 先部署服务端 0.1.15 与迁移 009，再用独立账号做两设备离线/重连、旧新图片、刷新登录、真实 AI 断流和 COS 恢复。仅登录应没有图片上传，显式开启完整备份后才同步。

完整发布还需解锁 Chrome、最低/稳定版本与 Windows 抽样、真实输入法/读屏、大数据规模、商店新素材和用户主观体验。本轮没有推送、部署或发布。

## 复跑与文件

```sh
npm run check
cd server
AARRE_TEST_DATABASE_URL=postgres://localhost/aarre_audit_20260909 npm test
npm run build
```

浏览器脚本需要 Vite 开发服务和仍可控制的原 Ego 任务空间 5：`finish-browser.mjs`、`finish-surfaces.mjs`、`finish-manager.mjs`。后续若任务空间已交还用户，先取得控制权；不能把这些脚本当作自动安装 Chrome 的替代品。脚本中的场景数据只用于视觉/交互验收。

打包使用 `node scripts/package-artifacts.mjs`，它要求干净 Git 提交且拒绝覆盖已有版本。输出版本、源码提交、构建/打包时间与所有文件哈希到 `outputs/Bookmark-Layer-0.6.0-build.json`。实际封装结果以该文件和根进展的交付记录为准。`SHA256SUMS` 覆盖本目录证据；原审计证据保持不变。
