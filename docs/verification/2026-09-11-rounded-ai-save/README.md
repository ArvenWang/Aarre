# Aarre 0.6.7 大圆角与打开即增强

本轮入口采用 44 × 44px 等大按钮、20px 按钮圆角、28px 外框圆角；半透明磨砂及减少透明效果的实色回退保留。尺寸参考 [Material Components 的官方形状尺度](https://github.com/material-components/material-components-android/blob/master/docs/theming/Shape.md)，按本产品控件尺寸定制。

## 功能

- 打开创建收藏表单后自动分析真实捕获的网页正文，使用已配置 Provider；表单显示分析中、摘要/标签、失败重试或跳过原因。编辑名称、目录和备注不等待分析。
- 确认前不创建 Chrome 书签、资源或同步任务。完成结果在 `chrome.storage.session` 中可复用 15 分钟、最多 32 个请求；后续写入清理过期记录，浏览器退出时清空会话缓存。只保留 AI 字段、哈希和绑定身份，不另存网页全文、源网址字段或 API Key。正文分析仍受现有隐私与保护规则约束。
- 已完成结果按请求、来源标签及捕获内容校验后复用；后台休眠后仍可复用。未完成时先保存，后台写回同一资源，使用原子事务保留用户稍后编辑的字段；已删除、内容变化或新设保护的资源不接受旧结果。
- 保存后的 AI 完成通知更新收藏库。后台中断后，正式增强队列仍保留补全任务，下次正常访问页面可继续。
- 45 秒 AI 总时限与表单 55 秒兜底，停止信号覆盖响应正文读取；参考 [MDN AbortSignal.any](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal/any_static)。

## 已解决的实际问题

真实 Chrome 首次检查发现保存后摘要变化，原有内存缓存不足以跨 MV3 后台休眠保留；已改成有期限的会话缓存，并通过重建后台实例的集成测试和 78 秒停留后的原生 Chrome 复测。另补了响应体读取的取消边界、保存过程中分析恰好完成的竞争条件、原子合并与界面刷新。
