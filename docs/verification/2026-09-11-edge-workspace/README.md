## 电脑端验收

1. 刷新已经打开的普通网页，右边应出现两个按钮；下方星标用于快捷收藏。
2. 上方按钮展开贴边菜单；拖动左边只调宽，顶部和底部不能调高。
3. 在底部直接提问；打开原来的长回答，窄宽度下也不应出现左右滚动或截断。
4. 完整收藏库只显示两项导航；设置按分组切换，未提交输入保持。
5. 滚动后细条出现，静止渐隐；检查日夜主题及输入框不被其他扩展遮挡。
