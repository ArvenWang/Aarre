# Aarre Chrome Web Store 上架材料

更新日期：2026-08-03

## 商店定位

**短描述（132 字以内）**

保留 Chrome 原生书签，在本机补充摘要、标签、智能检索、死链检测、整理提案与可撤销批量操作。

**完整描述**

Aarre 是 Chrome 原生书签的智能增强层，不建立一套需要重新导入的平行收藏库。

- 侧边栏快速查找、打开、收藏和询问已有收藏
- 中文、拼音首字母、标签、主题、摘要与检索别名的本地搜索
- 可选 BYOK：直连 Gemini、OpenAI 或 DeepSeek 生成摘要和标签
- 重复收藏、失效链接和大文件夹整理提案
- 所有移动和删除先预览，删除默认不选，执行前保存 30 天撤销快照
- 周/月洞察、主题图谱和旧收藏重新浮现
- 页面快照默认仅保存在本机；用户主动选择完整云端备份后可加密上传，API Key 和网页正文不经过 Aarre 服务器
- 一键导出全部本地智能层数据，不锁定用户

## 单一用途声明

Aarre 的单一用途是增强 Chrome 原生书签的查找、理解、整理和重新发现体验。所有权限都直接服务于这一用途。

## 权限披露文案

| 权限 | 面向审核与用户的说明 |
| --- | --- |
| `bookmarks` | 读取 Chrome 原生书签，并只在用户明确确认后创建、移动、改名或删除。Aarre 不建立平行书签库。 |
| `tabs` | 识别当前页面、打开用户选择的书签，并在已收藏页面位于前台时安排本机页面快照。 |
| `webNavigation` | 只监听已收藏页面主框架的加载完成、重定向和页面内路由变化，用于把截图绑定到正确的标签、最终网址与文档；不建立浏览历史副本。 |
| `debugger` | 仅用于用户显式启动的「补齐缺失封面」后台任务：对 Aarre 自己创建的专用标签页执行 Chrome 调试协议截图，使任务不占用前台、不打断用户浏览；不附加到用户正在浏览的其他页面，也不读取页面正文或上传任何数据。 |
| `activeTab` | 在用户主动收藏当前页时临时读取页面信息。 |
| `scripting` | 在用户主动收藏或已授权扫描时提取当前页面的标题、正文和公开元数据。 |
| `history` | 仅在本机提供地址导航建议；浏览历史不会上传或用于广告。 |
| `storage` | 保存扩展设置、状态和 AI 服务商 API Key；Key 不进入导出文件。 |
| `unlimitedStorage` | 保存本机页面快照、封面和智能元数据，避免 IndexedDB 配额导致静默丢失。 |
| `identity` / `identity.email` | 用于用户主动选择的 Google 登录与跨设备智能层同步，并核对 Aarre 账号是否与当前 Chrome 配置一致；全部本地功能无需登录。 |
| `sidePanel` | 提供 Chrome 侧边栏主界面。 |
| `contextMenus` | 提供“收藏当前页面/链接”的右键入口。 |
| `alarms` | 恢复长时间本地扫描和可选同步队列。 |
| `search` | 把用户明确提交的地址栏搜索交给 Chrome 默认搜索引擎。 |
| `favicon` | 读取 Chrome 已缓存的图标作为低风险界面提示，不把它当作高质量封面。 |
| `<all_urls>` | Chrome 原生星标不会授予临时网页权限，且 `captureVisibleTab()` 与后台截图任务要求真正的 `<all_urls>` 或临时 `activeTab`；为在新收藏后自动完成摘要、标签和截图，并在已收藏页面正常打开时补缺图或按 7 天新鲜度静默刷新，安装时需要网页访问权限。Aarre 的业务逻辑仍只处理 HTTP(S) 收藏；无痕、内网、银行、支付、医疗和用户排除页面不读取正文、不调用 AI、也不截图。 |
| AI 服务商请求（使用上述网站访问权限） | 用户配置自己的 Key 后，扩展从本机直连所选 Gemini、OpenAI 或 DeepSeek；不经 Aarre 服务器。 |

## 隐私问卷建议

- 不出售数据，不用于广告，不用于信用评估。
- 书签标题、网址、备注、网页正文和页面快照均属于用户数据。
- 默认本地处理；BYOK 调用只发送到用户选择的 AI 服务商。
- 云端默认关闭。“仅文字与设置”不上传图片；只有用户明确选择“完整云端备份”后，页面快照、封面和站点标识才会加密上传腾讯云私有 COS。
- API Key、网页正文、Cookie、完整浏览历史、Chrome 原生 ID 和受保护资源不上传 Aarre 云端。
- 云端使用服务端信封加密与 COS SSE-COS AES-256，不宣传为端到端加密；用户可以暂停同步、清除此设备或请求删除整个云端账号。
- 隐私政策入口：扩展包内 `privacy.html`，公开地址为 `https://sync.nexvoice.cc/privacy`；服务条款地址为 `https://sync.nexvoice.cc/terms`。
