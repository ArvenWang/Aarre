# Aarre 腾讯云容量、成本与扩容计划

最后更新：2026-08-03（已加入真实账号首次 metadata 同步）
适用范围：F14 完整云端同步、备份与重装恢复

## 1. 本机当前账号实测

本次不是按 PRD 猜测，而是读取当前 Mac 的 Chrome Default profile、扩展 IndexedDB、扩展 `chrome.storage.local` 与 Chrome 原生书签文件后，对“最新仍然有效”的记录做的投影。LevelDB 历史版本和已经删除的旧 icon 不计入云端有效数据。

| 项目 | 当前有效数量/体积 |
| --- | ---: |
| Chrome 原生网页书签 | 262 条 |
| Chrome 原生文件夹 | 16 个 |
| Aarre 当前资源 | 261 条；与原生相差 1 条，上线迁移时必须自动对账 |
| 资源白名单 metadata | 322,475 B |
| 109 张当前资源封面 | 1,478,330 B |
| 185 条站点身份 metadata | 18,101 B |
| 当前有效站点 icon bytes | 0 B；旧版本曾有 89 张，现已被本机迁移清理，重新增强后会增长 |
| 160 张页面快照 metadata | 20,007 B |
| 160 张页面快照 | 3,227,218 B |
| 可进入云端的设置、用量、报告等 | 约 356,247 B |
| **当前有效云端投影** | **5,422,378 B，约 5.17 MiB** |
| Chrome 扩展当前物理磁盘占用 | 约 16.1 MiB；包含 LevelDB 日志、历史版本、压缩前空间和运行时状态，不等于云端账单量 |

结论：以当前账号为例，补齐缺失站点 icon 后，预计有效 payload 约 6–8 MiB；加入 PostgreSQL 行/索引、AES-GCM envelope、COS 对象元数据后，主数据按 **7–9 MiB** 预留；加入香港主桶、新加坡异地副本、30 天版本与数据库备份后，长期平台占用按 **15–25 MiB/账号** 规划。

当前默认单账号硬额度 250 MiB，远高于本账号需求。软提醒设在 100 MiB；达到 200 MiB 时提示用户清理历史快照；250 MiB 只阻止新增云端资产，不阻止本机收藏、查看或导出。

## 2. 计费基线（腾讯云）

- 香港、新加坡 COS 标准存储当前刊例价均为 **0.136 元/GB/月**；标准多 AZ 为 0.15 元/GB/月。[腾讯云 COS 存储容量费用](https://cloud.tencent.com/document/product/436/53482)
- 香港 COS 外网下行与跨地域复制当前均为 **0.75 元/GB**；外网上传免费，同地域腾讯云内网上下行免费。[腾讯云 COS 流量费用](https://cloud.tencent.com/document/product/436/53863)
- KMS 专业版当前为 **7,699 元/月**，基础版/标准版已经停止新购；SSM 在当前账号也需要额外购买。受控 Alpha 不为一个 32-byte KEK 购买这两项高固定成本服务。[腾讯云 KMS 计费](https://cloud.tencent.com/document/product/573/34388)
- 当前生产采用两层加密：COS 默认 **SSE-COS AES-256**（不额外购买 KMS）保护对象静态存储；PostgreSQL 内容仍以逐用户 DEK 做 AES-256-GCM，DEK 由 `/etc/aarre/aarre.env` 中的版本化 root-only KEK keyring 包装。服务器 secret 已进入单独的 AES-256 加密恢复包，恢复口令同时保存在当前 Mac Keychain 和权限为 600 的离线恢复文件。未来进入高合规/多人运维阶段，再把同一 wrapper 接口迁移到腾讯云 KMS/SSM，不重写业务密文。
- 中国香港新购轻量应用服务器当前公开规格从 4 核 8 GB、180 GB SSD、30 Mbps、5 TB/月起，刊例价 **335 元/月**。购买页折扣可能变化，采购时以登录后的腾讯云预算单为准。[腾讯云香港轻量套餐](https://cloud.tencent.com/document/product/1207/89233)

真正需要重点监控的是 **COS 外网恢复流量**，不是静态存储容量。客户端直接从私有 COS 短签名 URL 懒下载，首次重装或新设备恢复才会产生明显下行。

## 3. 规模模型

| 规模 | 当前账号模式：有效主数据 | 主桶 + 异地副本 | 含版本/DB 备份的预算量 | 全体用户完整恢复一次的香港 COS 下行费 |
| ---: | ---: | ---: | ---: | ---: |
| 1 个当前账号 | 5.17 MiB | 10.34 MiB | 15–25 MiB | < 0.01 元 |
| 1,000 个同类账号 | 约 5.05 GiB | 约 10.1 GiB | 15–25 GiB | 约 3.79 元 |
| 10,000 个同类账号 | 约 50.5 GiB | 约 101 GiB | 150–250 GiB | 约 37.9 元 |

还必须做一个保守边界：如果每个账号都打满 250 MiB，1,000 账号为约 244 GiB 主数据，10,000 账号为约 2.38 TiB 主数据。平台告警、预算与采购按“实测 P50 + 50 MiB P90 + 250 MiB hard cap”三条曲线同时看，不能只用平均值。

## 4. 分阶段腾讯云方案

### 阶段 A：现在到受控 Alpha

- 计算：继续与 NexVoice 共用现有中国香港轻量应用服务器；Aarre 独立容器限 320 MiB/0.75 CPU。
- 数据库：共用 PostgreSQL 16 实例，但使用独立 `aarre_sync` database、独立 `aarre` role/password。
- 对象：香港私有标准 COS 主桶；新加坡私有标准 COS 灾备桶；两桶均开启版本控制和默认 SSE-COS AES-256。
- metadata 主密钥：版本化 32-byte KEK keyring 只存在服务器 root-only secret 和本机加密恢复包；应用只得到当前版本和仍需读取旧 DEK 的历史版本。
- 备份：每日 `pg_dump -Fc` 到新加坡灾备桶保留 35 天；每月备份保留 12 个月；每季度恢复到隔离数据库做演练。
- 采购：先按量计费，不买容量包。本阶段存储账单不足以抵消资源包的闲置风险。

生产机 2026-08-02 实测：3.6 GiB 内存中约 2.4 GiB 可用，系统盘 59 GiB 中约 44 GiB 可用；现有 PostgreSQL 约 112 MiB、NexVoice API 约 92 MiB。资源足够启动阶段 A，但必须保留下面的自动扩容门。

### 阶段 B：隔离 Aarre 计算

满足任一条件就购买新的腾讯云中国香港 4 核 8 GB 轻量应用服务器（公开刊例 335 元/月），把 Aarre API 与 Aarre PostgreSQL 一起迁出 NexVoice：

- 主机 `MemAvailable < 1 GiB` 持续 15 分钟，或 swap 使用量持续超过 512 MiB；
- Aarre 容器内存超过 224 MiB（70%）持续 15 分钟；
- 全机 CPU 超过 60% 持续 15 分钟；
- Aarre metadata API P95 超过 500 ms，或错误率超过 1%，且确认不是外部 Google/COS 故障；
- 受控活跃账号达到 500，或 30 天预测达到 1,000；
- 任一 Aarre 故障已经影响 NexVoice 的 API/数据库延迟。

这是故障域隔离采购，不是因为 COS 空间不足。服务器系统盘仍不保存用户图片。

### 阶段 C：托管数据库

满足任一条件，购买同地域腾讯云 PostgreSQL（云盘版、主备、高可用、至少 2 核 4 GiB，初始 100 GB）并启用销毁保护、自动备份和跨地域备份：

- Aarre 数据库主数据超过 10 GiB；
- 活跃账号达到 2,000；
- 连接池使用率持续超过 60%，或数据库查询 P95 超过 200 ms；
- 单机 PostgreSQL 的升级/备份维护窗口已经无法满足 RPO 24 小时、RTO 4 小时；
- 商业客户要求数据库 SLA 和自动主备切换。

腾讯云 PostgreSQL 的实时价格要求登录账号查看，采购时在价格计算器导出预算单并附到变更记录，禁止把文档里的示例价当报价。

### 阶段 D：高可用 API

活跃账号达到 10,000、API 峰值持续超过单机 40%，或商业 SLA 要求跨实例容错时：

- 两台腾讯云计算节点跨可用区部署 Aarre API；
- 腾讯云 CLB；
- 腾讯云 PostgreSQL 高可用；
- COS 香港主桶继续作为私有资产源，新加坡复制桶只作灾备；
- 日志进入腾讯云 CLS，告警进入腾讯云可观测平台。

## 5. 存储采购与扩容规则

1. 先按量计费；连续 60 天月度 P95 稳定后才买 COS 容量包/外网下行包。
2. 容量包买“未来 6 个月预测的 70%”，剩余由按量覆盖，避免一次高峰后长期闲置。
3. 当前有效存储/已购容量达到 50% 进入观察、70% 提交预算、85% 完成扩容；外网流量包同样使用 50/70/85 阈值。
4. 主桶只用标准存储。页面快照频繁覆盖/删除，低频与归档有 30/90 天最短存储和提前删除费，不适合活跃资产。
5. 灾备数据库日备 35 天后删除；月备 12 个月后删除。对象跨地域复制保留当前版本，历史版本 30 天后生命周期清理。
6. 每月记录：账号数、P50/P90/P99 bytes、asset 数、上传/下载流量、恢复次数、COS 版本量、数据库大小、备份大小与实际账单。
